## 🚀 Quick start

**No build step required.**

### Open directly

Download the project and open `index.html` in your browser.

> The contact form requires an HTTP(S) server and will not send when the
> page is opened using a `file://` URL.

### Serve locally

From the project folder, run:

```bash
npx serve.
```

Open the local address shown in your terminal.

> This option requires Node.js and npm. `npx` may download `serve` if it
> is not already available.

## ⚙️ Setup and customization

<details>
<summary><strong>💌 Activate the contact form</strong></summary>

<br>

The contact form uses [FormSubmit](https://formsubmit.co) to deliver
messages to the configured inbox.

1. Confirm that the form in `index.html` uses your intended email address.
2. Serve the site locally or deploy it over HTTPS.
3. Submit a test message.
4. Look for FormSubmit’s activation email and confirm the address.
5. Check your spam folder if the activation email does not appear.

After activation, test the form again to confirm messages arrive.

The portfolio also includes an email-app fallback.

</details>

<details>
<summary><strong>🎨 Make it your own</strong></summary>

<br>

| To change… | Update… |
| :--- | :--- |
| Personal introduction and section text | `index.html` |
| Project descriptions and destination links | `index.html` |
| Profile photo and dashboard previews | Files in `assets/` |
| Downloadable resume | `assets/resume.pdf` |
| Colours, spacing, and visual styling | Variables and rules in `styles.css` |
| Theme, navigation, and interactions | `script.js` |
| Contact details | Form configuration and links in `index.html` |

Keep filenames consistent, or update the corresponding references when
replacing assets.

</details>

<details>
<summary><strong>🌐 Publish with GitHub Pages</strong></summary>

<br>

1. Push the project to a GitHub repository.
2. Open the repository’s **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select your branch and the folder containing `index.html`.
5. Save and wait for GitHub to publish your site.

After deployment, check:

- Navigation and asset paths
- Dashboard and GitHub links
- Resume download
- Mobile layout and theme switching
- Contact form activation and delivery

</details>
